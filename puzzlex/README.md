# Publicare folder `puzzlex`

Acest folder trebuie încărcat pe vechiul server Pontes la adresa:

```text
https://static.pontes.ro/puzzlex/
```

Rolul fișierelor:

- `index.html` este linkul distribuit din aplicație și redirecționează utilizatorul către Google Play, App Store sau versiunea web;
- `help.html` este pagina de ajutor folosită și în paginile aplicației din magazine;
- `privacy.html` este politica de confidențialitate folosită în Google Play și App Store;
- `sigla.png` este logo-ul și imaginea folosită la previzualizarea linkului distribuit;
- `stil.css` conține stilurile comune pentru cele trei pagini HTML.

După încărcare trebuie verificate:

```text
https://static.pontes.ro/puzzlex/
https://static.pontes.ro/puzzlex/help.html
https://static.pontes.ro/puzzlex/privacy.html
```

Versiunea web a jocului este publicată separat la:

```text
https://puzzle.pontes.ro/
```
